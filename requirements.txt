# THE FIRST LINE IS LOAD-BEARING. torch 2.5.1 from plain PyPI is the CUDA build: a 906 MB wheel that
# hard-pins twelve nvidia-cu12 packages and triton, about 3 GB of downloads and ~6 GB unpacked, none
# of which is used because the app runs on CPU. The CPU wheel is 175 MB. An earlier version of this
# file explained that in a comment and left the pin bare, which does nothing — pip does not read
# comments. The extra index below is what actually selects the CPU build: it publishes
# torch-2.5.1+cpu, and under PEP 440 a local version matches `==2.5.1` and sorts above the plain
# PyPI release, so pip prefers it.
